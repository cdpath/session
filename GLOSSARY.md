# session

Glossary for the `session` CLI, which lists AI coding-agent sessions (pi, Claude Code, Codex, Droid) in one picker and resumes the selected one.

## Language

**Repo slug**:
A git repository's remote identity as `owner/repo` for `github.com` remotes, or `host/owner/repo` for any other host. Empty when the repository has no usable remote.
_Avoid_: slot, GitHub full name

**Repo directory name**:
The display-only fallback label for a session inside a git repository with no usable remote: the repository root's directory name. Never appears in JSON output.
_Avoid_: repo name, project name
